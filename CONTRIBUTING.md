
# Contributing to KeyRush

Thank you for your interest in contributing to KeyRush.

Contributions, suggestions, and improvements are welcome. Whether it's fixing a bug, improving the interface, or adding a useful feature, every meaningful contribution helps.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your improvements.
4. Test your changes before submitting.
5. Submit a pull request with a clear description.

## Guidelines

- Keep the code clean and readable.
- Avoid unnecessary dependencies.
- Maintain the existing design and functionality.
- Make sure existing features continue to work.
- Explain your changes clearly.

## Reporting Issues

If you find a bug or have an idea for improvement, open an issue on GitHub and provide enough information to understand it.

Thank you for helping make KeyRush better.
