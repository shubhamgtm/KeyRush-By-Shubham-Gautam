
# Changelog

All notable changes to KeyRush will be documented in this file.

This project follows a simple versioning system:
`MAJOR.MINOR.PATCH`

## [1.0.0] - 2026-11-16

### Added
- Typing speed test functionality.
- Basic, Medium, Hard and Extra Hard difficulty levels.
- Multiple typing paragraphs.
- Customizable test duration:
  - 15 seconds
  - 30 seconds
  - 45 seconds
  - 60 seconds
- Paragraph typing speed tracking.
- Individual key speed tracking.
- Personal highest WPM record.
- Typing performance graph.
- Clean and responsive user interface.
- Real-time typing statistics.

### Features
- Live WPM calculation.
- Typing accuracy tracking.
- Personal performance monitoring.
- Different typing difficulty levels.

### Project
- Initial public release of KeyRush.
- Added project documentation.
- Organized project assets and source files.
