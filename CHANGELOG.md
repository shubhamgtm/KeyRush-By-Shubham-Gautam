
# Changelog

All notable changes to KeyRush are documented here.

## [1.0.0] - 2026-11-15

### Added
- Initial release of KeyRush.
- Four difficulty levels.
- Custom typing test durations.
- Multiple typing paragraphs.
- WPM and key speed tracking.
- Accuracy measurement.
- Personal highest score tracking.
- Performance graphs.
- Responsive user interface.
