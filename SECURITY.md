
# Security Policy

The security of KeyRush matters.

## Reporting a Vulnerability

If you discover a security issue in KeyRush, please report it responsibly.

When reporting an issue, include:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Its possible impact.
- Any relevant screenshots or technical details.

## Responsible Disclosure

Please avoid publicly sharing vulnerabilities before they have been investigated.

Do not exploit vulnerabilities, access other people's data, or disrupt the service.

Thank you for helping keep KeyRush safe.
